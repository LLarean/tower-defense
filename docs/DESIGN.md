# Дизайн игры

Кооперативный Tower Defense на 1–4 игроков, построенный вокруг сочетания стихий.
Одна стихия наносит урон, а две стихии на одном монстре вызывают **реакцию**, которая раскрывается на толпе.

## Цикл игры

1. Волна объявлена: игроки строят и улучшают башни за своё золото.
2. Монстры идут по пути к базе. Если монстр дошёл, общие жизни уменьшаются.
3. Золото за убийство делится поровну между всеми игроками, чтобы никто не воровал убийства.
4. Победа — все волны карты отбиты, поражение — жизни закончились.

## Стихии и статусы

| Стихия | Статус на монстре | Эффект |
|---|---|---|
| Огонь | Горение | Урон со временем |
| Вода | Мокрый | Без урона, проводник для реакций |
| Лёд | Охлаждение | Замедление |
| Молния | Заряд | Короткое оглушение |
| Яд | Отравление | Накапливаемый урон со временем |
| Земля | Раскол | Монстр получает больше урона |

## Реакции

Реакция срабатывает, когда на монстре с одним статусом появляется второй. Оба статуса при этом снимаются, кроме отмеченных случаев.

| Пара | Реакция | Эффект |
|---|---|---|
| Вода + Молния | Электрошок | Цепная молния по всем мокрым в радиусе |
| Вода + Лёд | Заморозка | Монстр стоит на месте |
| Заморозка + Земля | Раскалывание | Большой урон и осколки по соседям |
| Огонь + Вода | Пар | Облако по области: урон и замедление |
| Огонь + Лёд | Термошок | Разовый большой урон |
| Огонь + Яд | Взрыв газа | Урон по области, поджигает соседей |
| Огонь + Молния | Перегрузка | Взрыв с отбрасыванием назад по пути |
| Яд + Вода | Ядовитая лужа | Зона на дороге, отравляет проходящих |
| Земля + Вода | Грязь | Зона на дороге, замедляет |
| Земля + Огонь | Магма | Зона на дороге, поджигает |
| Лёд + Молния | Сверхпроводник | Снимает броню |
| Яд + Молния | Коррозия | Снимает броню, усиливает отравление |

## Башни

- Шесть базовых башен, по одной на стихию, у каждой три уровня. Улучшение повышает урон, дальность и силу статуса.
- На третьем уровне игрок выбирает одну из двух специализаций. Например, у огня: «Огнемёт» с конусом и частым горением или «Метеор» с медленным ударом по области.
- Дорогие гибридные башни накладывают сразу два статуса, а значит, вызывают реакцию сами: «Буря» (Вода + Молния), «Вулкан» (Огонь + Земля). Они дороже пары обычных башен, но сразу открывают сильные сочетания.

## Карты

1. **Луг** — один путь, обучение.
2. **Перекрёсток** — два входа сливаются в один путь.
3. **Река** — путь петляет вдоль воды: удобно мочить и шокировать.
4. **Перевал** — длинный путь через снег с узкими местами.
5. **Вулкан** — три входа, финальная проверка сочетаний.

## Ощущения

- Каждая реакция имеет узнаваемый эффект, звук и всплывающую надпись.
- Монстры получают вспышку при ударе, у смерти есть эффект, на крупных реакциях трясётся камера.
- Цель по производительности — 500+ монстров и 100+ одновременных эффектов при 60 FPS на средней машине.
